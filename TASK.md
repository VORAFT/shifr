# Задача: Создание переиспользуемого компонента Tabs

## Цель
Создать переиспользуемый компонент табов с помощью класса `Tabs`, который позволит разделить интерфейс для зашифровки и расшифровки текста.

[Material-UI Tabs](https://v6.mui.com/components/tabs/) - использовать как пример для понимания логики работы табов (переключение, активация/деактивация панелей, управление состоянием). **Важно**: стили копировать 1:1 не требуется - главное, чтобы работала логика переключения табов.

## Требования

### 1. Создание класса Tabs
- Реализовать класс `class Tabs {}` в JavaScript
- Класс должен принимать селектор контейнера табов при инициализации: `new Tabs('#my-tabs-id')`
- Класс должен управлять переключением между вкладками (активация/деактивация табов и соответствующих панелей контента)

### 2. HTML структура
- Структура табов должна быть верстаемой через HTML с использованием классов
- Примерная структура:
  - Контейнер табов с уникальным ID
  - Список кнопок/ссылок для переключения табов
  - Панели контента, соответствующие каждому табу

### 3. Переиспользование
- Класс должен быть переиспользуемым для нескольких наборов табов на одной странице
- Каждый экземпляр должен работать независимо: `new Tabs('#tabs-1')`, `new Tabs('#tabs-2')`

### 4. Применение для разделения функционала
- Использовать компонент Tabs для разделения интерфейса:
  - **Таб "Зашифрувати"**: содержит форму для ввода текста и ключа, кнопку "Зашифрувати", поле результата
  - **Таб "Розшифрувати"**: содержит форму для ввода текста и ключа, кнопку "Розшифрувати", поле результата
- Каждый таб должен иметь свой независимый интерфейс для соответствующей операции
